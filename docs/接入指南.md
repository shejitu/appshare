# 接入指南（Android）

三步：**查版本 → 下载 → 拉起安装器**。全程不需要后端服务，就是读一个静态 JSON。

## 0. 准备：确认 appId

`appId` 是仓库里的目录名，全小写，例如 `scrollprompter`、`haididoor`。
发布时用 `--app-id` 指定，客户端用它拼检查地址。

## 1. 检查更新

```
https://cdn.jsdelivr.net/gh/shejitu/appshare@main/<appId>/version.json   ← 国内首选
https://ghproxy.net/https://raw.githubusercontent.com/shejitu/appshare/main/<appId>/version.json
https://raw.githubusercontent.com/shejitu/appshare/main/<appId>/version.json
```

判断逻辑只有一句：**`versionCode > 本机 versionCode` 就有更新**。

> 不要拿 `versionName` 做字符串比较。"1.10" 按字典序小于 "1.9"，会漏更新。

`version.json` 里 `apk.mirrors` 是同一安装包的备用地址，按顺序试，第一个成功就停。

### 现成代码

`client/AndroidUpdater.kt` 直接拷进工程即可：

```kotlin
AppUpdater.check(this, "scrollprompter") { info, err ->
    when {
        err != null -> Log.w("upd", err.message ?: "")
        info == null -> { /* 已是最新 */ }
        else -> showUpdateDialog(info)   // info.versionName / info.notes / info.mandatory
    }
}
```

`check()` 会依次尝试 **jsDelivr → ghproxy.net → raw** 三个地址，全部失败才回调 error。

## 2. 下载

```kotlin
AppUpdater.download(this, info,
    onProgress = { done, total -> progressBar.progress = (done * 100 / total).toInt() },
    onDone = { file -> AppUpdater.install(this, file) },
    onError = { e -> Toast.makeText(this, e.message, Toast.LENGTH_LONG).show() })
```

下载器已经做了三件必须做的事：

1. 存到 `cacheDir/updates/`，`.part` 临时文件，成功才改名；
2. 校验 `size`；
3. **校验 `sha256`** —— 不匹配直接删掉重试下一个镜像。这一步别省，公开仓库的安装包谁都能镜像，没有校验就等于把安装权限交给中间人。

## 3. 安装

```kotlin
AppUpdater.install(this, apkFile)
```

需要的配置：

**AndroidManifest.xml**

```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.REQUEST_INSTALL_PACKAGES" />

<application ...>
    <provider
        android:name="androidx.core.content.FileProvider"
        android:authorities="${applicationId}.fileprovider"
        android:exported="false"
        android:grantUriPermissions="true">
        <meta-data
            android:name="android.support.FILE_PROVIDER_PATHS"
            android:resource="@xml/file_paths" />
    </provider>
</application>
```

**res/xml/file_paths.xml**

```xml
<?xml version="1.0" encoding="utf-8"?>
<paths>
    <cache-path name="updates" path="updates/" />
</paths>
```

Android 8.0+ 没有引导过「安装未知应用」的用户，`install()` 会先跳转到系统授权页，
授权回来再调一次即可（示例里没做自动重试，实际工程可以在 `onResume` 里重试一次）。

## 4. 几个坑

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `INSTALL_FAILED_VERSION_DOWNGRADE` | 新包 `versionCode` 没涨 | 发版时 `--version-code` 必须递增 |
| 装出两个 App | `applicationId` 改了 | 升级包的包名必须和已装版本一致 |
| 提示"解析包错误" | 下载被截断 / 被网关改坏 | 已校验 size + sha256，仍失败就换镜像 |
| 检查更新拿到旧版本 | raw / jsDelivr 有 CDN 缓存（约 5 分钟） | 请求加 `?t=<时间戳>` 打破缓存（示例代码已加） |
| 国内完全连不上 raw | 域名被墙 | 优先用 `cdn.jsdelivr.net` 那条 |

## 5. Windows 端 / 其他语言

同样的 JSON，逻辑一样。Python 示例：

```python
import json, urllib.request

def check(app_id, local_code):
    url = f"https://cdn.jsdelivr.net/gh/shejitu/appshare@main/{app_id}/version.json"
    with urllib.request.urlopen(url, timeout=15) as r:
        info = json.load(r)
    return info if info["versionCode"] > local_code else None
```
